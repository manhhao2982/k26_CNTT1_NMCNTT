# Tài liệu hướng dẫn cài đặt VS Code

## 1. Download VS Code về máy tính cá nhân
![Ảnh minh họa](https://preview.redd.it/what-are-the-cli-download-versions-and-why-would-you-choose-v0-i2xsjy3o5j2c1.png?width=1996&format=png&auto=webp&s=43e679d8b387d518657400d0beb318c5fd85a1fc)

- Tải VS Code theo hệ điều hành máy đang sử dụng, tránh tải nhầm hệ thống báo lỗi.
- Để vào trang tải, gõ: *https://code.visualstudio.com/*
- Truy cập website, click vào **Download** để tải.
- Sau khi tải file về hãy nhấn đúp chuột vào file và nhấn **NEXT** cho tới khi hoàn thành
- Xem cách cài cụ thể: [vd hướng dẫn tải và cài VS Code](https://youtu.be/MTGv1b75r_g)
## 2. Ví dụ về một câu lệnh trong VS Code
```
a=3

sum=a+b
Print  "sum"
```
