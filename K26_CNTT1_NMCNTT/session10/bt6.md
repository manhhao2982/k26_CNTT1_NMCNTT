## Phần 1: Phân tích
- Sai lầm 1: Nam cho rằng mã nguồn cần định dạng phức tạp, văn bản Rich Text có nhiều màu sắc, phông chữ và định dạng kiểu văn bản 
```
Tuy nhiên việc có nhiều định dạng sẽ làm hỏng cú pháp trong file khi up lên github vì thực tế mã nguồn chỉ cần văn bản thuần, đơn giản
```
- Sai lầm 2: Nam đã hiểu lầm file Rich Text phù hợp để lưu trữ mã nguồn
```
File Rich-Text chứ nhiều các định dạng gây nặng file, đồng thời khi up lên github sẽ bị lỗi định dạng, khi chỉnh sửa sẽ gây ra lỗi xung đột toàn bộ file, ngoài ra khi trong quá trình tải lên github nếu có vấn đề về đường mạng thị nội dung toàn file sẽ bị hỏng hoàn toàn.
```
- Markdown bản chất là một văn bản thuần, chứa các định dạng nhẹ gọn gàng và đặc biệt sẽ không bị hỏng hoàn toàn file nếu như gặp một sự cố về internet , khi tải lên github vẫn sẽ giữ nguyên được định dạng ban đầu
